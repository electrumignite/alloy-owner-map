# Alloy Owner Network Map

An independent map of every Alloy Personal Training studio — owners, studio contacts, Google ratings and network growth — built from public data as a resource for Alloy owners. Published by [Electrum Ignite](https://electrumignite.com).

**Live map:** https://map.electrumignite.com/

Sources: alloypersonaltraining.com (studios and contacts), Alloy's 2026 Franchise Disclosure Document Item 20 (owner names), Google (ratings and reviews), 2026 FDDs on file with the Wisconsin DFI (network history and peer brands). The map updates monthly.

Corrections or name removal: see "About this map" on the live map.

Independent project. Not affiliated with, endorsed by, or sponsored by Alloy Personal Training Franchising, LLC. "Alloy Personal Training" is a trademark of its owner and is used here only to identify the studios shown.
